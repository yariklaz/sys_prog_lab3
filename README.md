# Синтаксичний аналізатор (Mini-C)
**Виконав:** Лазирко Ярослав Богданович, студент групи ТК-32

## Про проєкт
Навчальний транслятор для підмножини мови C. Написаний на C++ з використанням Flex та Bison. Програма читає код, будує Абстрактне Синтаксичне Дерево (AST) і виконує:
1. Генерацію цільового коду на Python (`code.py`).
2. Семантичне обчислення (виводить значення змінних у термінал).
3. Експорт AST у JSON для візуалізації в браузері (D3.js).
